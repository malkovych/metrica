Допомога з застосунком Metrica для iOS

Зв’язок

Email: support@metrica.app

Час відповіді: 1–2 робочі дні (Пн–Пт, 10:00–18:00 EET).

Часті питання

Як увійти?
Email + пароль або Sign in with Apple. Демо (sandbox): owner@metrica.app / password.

Немає даних / офлайн?
Перевірте інтернет. Застосунок показує останній кеш і банер «офлайн».

Як підключити Poster або WooCommerce?
Налаштування → Джерела → «Додати джерело» (веб-флоу через Hub).

Push не приходять?
Увімкніть сповіщення для Metrica в iOS Settings → Notifications.

Видалити акаунт?
Напишіть на support@metrica.app з email облікового запису.

Системні вимоги

  • iPhone, iOS 17.0+
  • Активний Hub API акаунт

Support (English): Email support@metrica.app. Response within 1–2 business days.
