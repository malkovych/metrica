Metrica

Мобільний дашборд для власників ресторанів та інтернет-магазинів. Один акаунт — кілька бізнесів: виручка сьогодні, аналітика, PDF-звіти та push-сповіщення про аномалії.

Можливості

  • Екран «Сьогодні» з KPI та блоками з Hub API
  • Аналітика: revenue, menu-abc, sales, customers
  • Звіти PDF та share sheet
  • Push-сповіщення з deep-link на дашборд
  • Режими resto / ecom, uk / en

Джерела даних

Poster (RestoPro), WooCommerce, OpenCart — через єдиний аналітичний Hub. Токени джерел не зберігаються на пристрої.
